# Week 09 - Capstone: Post-Training Mini-Lab

## Theme

Convert learning into a strong interview artifact.

## Weekly Deliverable

Polished GitHub repo + short technical writeup.

## Sessions

| Day | Topic | Deliverable |
|---|---|---|
| Day 1 | Define the Experiment | Experiment spec |
| Day 2 | SFT Baseline & Eval Harness | SFT baseline + eval |
| Day 3 | DPO/IPO Run with Ablations | DPO run + ablation results |
| Day 4 | GRPO/RLVR Run | GRPO/RLVR results |
| Day 5 | Results & Writeup | Capstone writeup in artifacts/ |

## Must-Know Interview Outcomes

By the end of this week, I should be able to:

1. Define a crisp experiment: model, dataset, eval, success metric, baseline.
2. Stand up an SFT baseline with an eval harness.
3. Run DPO/IPO with meaningful ablations.
4. Run or simulate GRPO/RLVR with verifiable rewards.
5. Write results honestly: what improved, what failed, what to scale next.

## Folder Map

- `day-0X-.../` - one 2-hour session each (`session.md`, `work.ipynb`, `deliverable.md`)
- `code/` - reusable code for the week
- `notes/` - exploratory notes, paper notes, scratch derivations
- `artifacts/` - polished outputs (diagrams, notebooks, reports)
- `week-summary.md` - condensed explanation written after finishing the week
- `retrospective.md` - what clicked, what was confusing, what to review
